MCP-Server

Mit dem MCP-Server kann ein KI-Assistent WUP-Dateien lesen, prüfen und nach Anweisung ändern — mit genau denselben Regeln und Automatiken wie der Editor.

Was er kann · Installieren · Anbinden · Gerätebelegung · Beispiele · Werkzeuge · Daten

Was er kann

MCP (Model Context Protocol) ist ein offener Standard, über den KI-Assistenten wie Claude auf Werkzeuge zugreifen. Der WUP-MCP-Server ist ein solches Werkzeug. Er läuft auf dem eigenen Rechner und enthält keine eigene Fachlogik: Er lädt den WUP-Editor ohne Browser und ruft dessen Funktionen auf. Was der Server meldet, meldet also auch der Editor.

  • Eine Datei oder einen ganzen Ordner gegen alle 25 Prüfregeln prüfen.
  • Automatiken rechnen: Über- und Unterschnitt, Freistiche, Sperrflächen und weitere.
  • Werte in vielen Bearbeitungen zugleich ersetzen.
  • Steuercodes erklären und in der WUP-Schnittstellenbeschreibung nachschlagen, samt Seitenbildern.

Der Assistent formuliert daraus Antworten, fasst Befunde zusammen oder schlägt Korrekturen vor. Geändert wird eine Datei nur, wenn ausdrücklich ein Zielpfad genannt ist.

Installieren

Voraussetzung

Node.js ab Version 18. Weitere Pakete sind nicht nötig. Ob Node.js vorhanden ist, zeigt:

node --version

Herunterladen

Entweder mit Git:

git clone https://github.com/Hui-161/WUP_TOOLS.git

oder auf GitHub über „Code“ → „Download ZIP“ und den Ordner entpacken. Der Server braucht den ganzen Ordner, nicht nur seine eigene Datei, weil er den Editor daraus lädt.

Ausprobieren

Im heruntergeladenen Ordner listet dieser Befehl die Werkzeuge des Servers auf:

node Wup/Mcp/wup_frage.js --liste

Und dieser prüft eine der mitgelieferten Beispielwände:

node Wup/Mcp/wup_frage.js wup_pruefen '{"pfad":"Wup/03_Beispiel-synthetisch/SEMA/IW01.WUP"}'

Ohne Gerätebelegung meldet die Prüfung jede Nagelreihe mit P-20. Das ist richtig so, siehe Gerätebelegung.

An einen Assistenten anbinden

Der Server spricht über Standardein- und -ausgabe (stdio). Jedes Programm, das MCP-Server so starten kann, kann ihn nutzen. In allen folgenden Beispielen ist /pfad/zu/WUP_TOOLS durch den Ordner zu ersetzen, in den heruntergeladen wurde.

Claude Code

Im Ordner WUP_TOOLS gestartet, findet Claude Code den Server über die mitgelieferte Datei .mcp.json selbst und fragt einmal, ob er ihn verwenden darf. Für alle Ordner verfügbar macht ihn:

claude mcp add --scope user wup -- node /pfad/zu/WUP_TOOLS/Wup/Mcp/wup_mcp_server.js

Claude Desktop

In der Konfigurationsdatei claude_desktop_config.json den Server eintragen. Sie liegt unter Windows in %APPDATA%\Claude\, unter macOS in ~/Library/Application Support/Claude/ und lässt sich in Claude Desktop über die Einstellungen unter „Entwickler“ öffnen.

{
  "mcpServers": {
    "wup": {
      "command": "node",
      "args": ["C:/Werkzeuge/WUP_TOOLS/Wup/Mcp/wup_mcp_server.js"]
    }
  }
}

Unter Windows den Pfad mit Schrägstrichen / schreiben oder jeden umgekehrten Schrägstrich verdoppeln. Danach Claude Desktop neu starten.

Andere Programme

Befehl node, Argument der vollständige Pfad zu Wup/Mcp/wup_mcp_server.js, Übertragung stdio.

Gerätebelegung

Im Browser fragt der Editor beim ersten Start, welches Nagel- oder Klammergerät hinter welchem NR-Index steht. Der Server hat keinen Browser und liest die Belegung deshalb aus der Datei Wup/Mcp/profil.json:

{
  "nr_indizes": {
    "10": { "name": "Klammergerät 1", "psf_offset": 7 },
    "20": { "name": "Klammergerät 2", "psf_offset": 20 }
  }
}

psf_offset ist der Sperrflächen-Abstand in Millimetern. Die Werte stehen in den Herstellerunterlagen der Anlage. Eine Datei an anderer Stelle lässt sich über die Umgebungsvariable WUP_PROFIL angeben. Ist die Datei fehlerhaft, meldet der Server das, statt mit einer leeren Belegung weiterzurechnen. Nach einer Änderung den Server bzw. den Assistenten neu starten.

Beispiele

Was man einem angebundenen Assistenten sagen kann:

  • „Prüfe alle WUP-Dateien in D:/Auftrag 123 und fasse die Fehler je Wand zusammen.“
  • „Warum meldet die Wand EG05 P-03, und welche Automatik behebt das?“
  • „Rechne für AW01.WUP die Auto-Sperrflächen und speichere das Ergebnis als AW01_neu.WUP.“
  • „Was bedeutet der Steuercode 222?“
  • „Wie ist eine Nagelreihe in der Schnittstellenbeschreibung definiert? Zeig mir die Seite.“

Werkzeuge des Servers

WerkzeugZweck
wup_datei_analysierenKopfdaten, Lagen, Bearbeitungen und WUP-Version einer Datei.
wup_pruefenAlle Prüfregeln für eine Datei.
wup_ordner_pruefenPrüfung aller Dateien eines Ordners.
wup_roundtrip_pruefenKontrolle, dass eine unveränderte Datei byte-gleich zurückkommt.
wup_automatikAutomatiken rechnen, Ergebnis auf Wunsch schreiben.
wup_werte_ersetzenWerte in vielen Bearbeitungen ändern.
wup_steuercodeEinen Steuercode in seine Bedeutung zerlegen.
wup_referenzKurzfassung des Formatwissens nach Themen, mit den Prüfregeln und dem Profil.
wup_spezifikationSuche in der WUP-Schnittstellenbeschreibung (V3.5 deutsch, 3.7 englisch), mit Seitenbildern.
wupworks_befehlErzeugt den Befehl für die Übergabe an die Maschinensoftware, führt ihn aber nicht aus.
wup_server_statusVersionen, Gerätebelegung und fehlende Dateien.

Geschrieben wird nur an einen ausdrücklich genannten Zielpfad, nur als .wup, nie in die Werkzeug- und Beispielordner und nur ohne offene Fehler-Befunde, außer der Assistent bestätigt das ausdrücklich.

Wohin die Daten gehen

Der Server selbst greift nicht aufs Netz zu und sendet nichts an die Maschine. Was er zurückgibt, liest aber der KI-Assistent — und der schickt es zur Verarbeitung an seinen Anbieter, bei Claude an Anthropic. Personenbezogene Kopffelder einer WUP-Datei (etwa Bearbeiter, Kunde, Bauvorhaben, Ort) gibt der Server deshalb nur geschwärzt aus. Projektnamen, Maße und Bearbeitungen gehen dagegen mit. Ob das für die eigenen Dateien in Ordnung ist, entscheidet der eigene Betrieb.

Ergebnisse prüfen. Was ein Assistent mit dem Server ändert, ist ein Vorschlag. Jede geschriebene Datei ist vor der Fertigung im Editor anzusehen und fachlich zu prüfen.
